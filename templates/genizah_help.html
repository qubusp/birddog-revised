Help: what is where

Genizah gathers every tool for finding, cataloguing and studying records from Ukrainian archives. This page says which tool to open for which job, and how they fit together.

Start here

  1. Sign in once, with your Birddog account. Accounts are by invitation; ask an admin for one. The same email and password work in every tool below.
  2. Pick the tool for your task from the table below, or from the cards on the Genizah page.
  3. Change your password in Birddog ({{ tool_link('birddog', 'Birddog') }} → Profile → Change password). The new password is copied to the other tools for you.

How it fits together

  1. The archives publish scans on uk.wikisource.org and Wikimedia Commons.
  2. Pipelines copy them into the catalog every night: pages, files, their metadata and changes (run by Airflow).
  3. Claude reads the scanned books page by page: the full text, each register entry, and the places named. Big books wait for an admin's approval first.
  4. People check and correct what was found, in Mathesar or the review notebook.
  5. Everyone uses the results: search and alerts in Birddog, maps in Grafana, analysis in JupyterHub, and the map of where each value came from in Marmot.

Words used here

Archive, fond, opus, case
The archive's own hierarchy: an archive holds fonds (collections), a fond holds opuses (inventories), an opus lists cases (files).
Page
A wiki page describing one level of that hierarchy.
Document, scan, book
A file linked from a page, usually a scanned PDF; a multi-page one is a book.
Place match
A place name read in a book, linked to a modern location in the catalog's location list.
Mention, quote
One place as written on one page, with the few words around it, so you can check it on the scan.
